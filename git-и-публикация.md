# Слайд 22. Git и публикация на GitHub — что делать студенту

Кейс-задание требует: создать удалённый репозиторий, инициализировать локальный в папке
с проектами практики, добавить файлы в индекс, сделать первый коммит, связать с удалённым
репозиторием и выполнить `git push origin master`, затем показать файлы на GitHub.

**Репозиторий специально не создан заранее** — все шаги выполняет студент, потому что
именно их он показывает скриншотами на слайде 22. Содержимое репозитория уже готово.

## Порядок действий

### 1. Создать удалённый репозиторий (скриншот `S22-01`)

1. Войти на https://github.com под своим логином.
2. `New repository` → имя, например `pm02-java-practice`.
3. Тип — **Public** (если руководитель требует публичный доступ), галочки
   `Add a README`, `.gitignore`, `license` **не ставить** — иначе push будет конфликтовать.
4. Скопировать адрес репозитория вида `https://github.com/<логин>/pm02-java-practice.git`.

### 2. Инициализировать локальный репозиторий (скриншоты `S22-02`, `S22-03`)

В Терминале:

```bash
cd /путь/к/synergy/proizvodstvennaya-praktika-pm02/java

# один раз: представиться (подставьте своё имя и почту от GitHub)
git config user.name  "Лапинин Игорь Олегович"
git config user.email "ВАША_ПОЧТА"

git init -b master                                  # S22-02
git add -A                                          # S22-03
git status                                          # проверить список файлов
git commit -m "Производственная практика ПМ.02: приложение для автошколы и мини-калькулятор"
```

Ожидаемый результат: `32 files changed` — если файлов заметно больше, значит в индекс
попал `bin/`; проверьте, что `.gitignore` лежит в папке `java`.

### 3. Связать и опубликовать (скриншот `S22-04`)

```bash
git remote add origin https://github.com/<логин>/pm02-java-practice.git
git push -u origin master
```

Если GitHub требует токен вместо пароля — создайте Personal Access Token
(Settings → Developer settings → Tokens (classic), права `repo`) и используйте его как пароль.

### 4. Показать результат (скриншот `S22-05`)

Открыть страницу репозитория на GitHub — видно загруженные файлы и папки.
Снять скриншот всей страницы.
